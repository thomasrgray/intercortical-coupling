# Respiration, GC/PC LFP and sorted-unit firing-rate spectra

The repository contains **data loaders**, not the original large session recordings. Actual firing-rate power requires sorted spikes; do not infer firing from LFP voltages.

## Input contract

- Pressure: `board-ADC-00.dat`, unsigned 16-bit Intan board ADC; sample rate must match the original `trial_info_frame.csv` recording.
- LFP: `cleaned_lfp.npz` generated by `coupling-prepare`. Requires QC masks, region labels GC/PC, chronological numeric `event_id`, and original TTL alignment.
- Optional spikes: sorted spike arrays in session blech_clust HDF5 (with `unit_descriptor`, `spike_trains/dig_in_N/spike_array`) or the canonical validated spike NPZ supported by `coupling-spike-noise`. The spike config supplies explicit region and stimulus mapping.

From the repository root:

```bash
python -m pip install -e '.[spikes]'
python respiration_sniffing/03_neural_spectra.py \
  --adc "/media/thomas/Data/TG22/Feb2_OrthoRetro_TG22_260202_170014/board-ADC-00.dat" \
  --trial-info "/path/to/trial_info_frame.csv" \
  --lfp "/path/to/lfp_prepared/cleaned_lfp.npz" \
  --spikes "/media/thomas/Data/TG22/Feb2_OrthoRetro_TG22_260202_170014/SESSION.h5" \
  --spike-config "configs/spike_noise.feb2.local.json" \
  --raw-fs 30000 \
  --output "results/respiration_neural_TG22_Feb2"
```

Use the **actual** sorted-spike HDF5 path, not the placeholder `SESSION.h5`. If sorted spikes are unavailable, omit **both** `--spikes` and `--spike-config`. The analysis then produces correctly labeled respiration and LFP spectra **without** a firing-rate curve.

To add the measured spectra to panel B of the existing four-panel figure (panel A retains the **200 ms** scale bar):

```bash
python respiration_sniffing/02_figure.py \
  --adc "/path/to/board-ADC-00.dat" \
  --trial-info "/path/to/trial_info_frame.csv" \
  --spectra "results/respiration_neural_TG22_Feb2/spectra.csv" \
  --output "results/respiration_neural_TG22_Feb2/figure_ABCD.pdf"
```

## Outputs and analysis

- `respiration_neural_spectra.pdf/png`: 0–12 Hz power, solid orthonasal vs dashed retronasal.
- `spectra.csv`: raw PSD, SEM, unit-area-normalized shape, signal type, and accepted-channel/unit counts.
- `provenance.json`: input paths, normalization, smoothing, Welch settings and selection rules.

Method: full −0.5 to +2.5 s trial epochs; Welch PSD at 1 kHz, Hann 1 s windows with 50% overlap, per-window detrending. Respiration is bandpassed 0.5–20 Hz and z-scored per trial; LFP is already referenced/filtered upstream; spike counts are converted to Hz and smoothed with a 25-ms Gaussian before spectral estimation. Compute PSD within each trial, average accepted trials within each eligible channel/unit, then equal-weight channels/units. Spike mode uses only laser-off trials and matches `DINn:triali` against the original stimulus table. Matched odors oBA/oIA (ortho) versus BA/IA (retro) are pooled within route, excluding S/BK.

The plotted *shape* spectra are normalized to unit area within 1–12 Hz, because raw pressure, LFP and firing-rate PSDs have different units. Their numeric magnitudes cannot be directly compared. The raw PSDs remain available in the CSV. These are descriptive session-level results, not coherence, and channel/unit counts are not independent biological replication.

## Verification

```bash
python -m unittest discover -s tests -p 'test_respiration_neural_spectra.py' -v
```

Confirm the `trial_info_frame.csv`, LFP archive and sorted spike file are from the **same** session. In particular, do not assume any trial numbering if preprocessing removed trials or mismatched the underlying DIN streams. Inspect the emitted spectra, original pressure, neural QC and synchronized timestamps before biological interpretation.
